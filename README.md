# Circle Style Kabaddi Live Score & Graphics Overlay (v3)

## What's Included in v3
- **Aggressive Slam + Fire Effects on Ground Intro:** Bold `Anton` & `Teko` broadcast typography with rising flame glow and impact transition (`slamIn`).
- **VS Screen with Team Logos & Captain Photos:** Displays both team logos, English + Punjabi names, and captain photos.
- **Team A & Team B Squads with Player Photos:** Each player entry supports `Name (Role) | Photo URL` with automatic initials avatar fallback if no photo URL is provided.
- **Left-Side Corner Scoreboard:** Top-left corner scoreboard with continuously scrolling English + Punjabi team names (`Noto Sans Gurmukhi`) and team logos.
- **Bottom Scrolling Ticker & Sponsor Rotation:** Preserved and synced in real time via Socket.io.
