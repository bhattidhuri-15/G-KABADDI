# Circle Style Kabaddi Live Score & Graphics Overlay (v2)

## Features
- **Ground Intro, Team vs Team, Team A & B Squads, & Top-Right Corner Live Scoreboard** (`+1`, `+0.5`, `-0.5`)
- **Bottom Scrolling Ticker Bar** with customizable badge & live announcements
- **Top-Left Sponsor Logo Rotation** supporting both image URLs and text badges with configurable timer
- **Real-time Sync** between `/admin` controller and `/overlay` OBS/vMix Browser Source

## Render.com Deployment
1. Upload the files inside `circle-kabaddi-live-score-v2` to GitHub.
2. Deploy on Render.com (`Build Command`: `npm install`, `Start Command`: `node server.js`).
